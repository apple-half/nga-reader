# 0.1.10 板块名称搜索验证

## 行为与来源

点击“我的板块”旁的加号，默认按名称、简介、分类和常用别名搜索NGA首页公开入口；普通板块直接添加并打开，已有板块打开且保留自定义名称。保留链接／编号添加。合集单独标记，只能主动打开官网，不映射成父板块。

目录来源是在用户指定的[官方首页](https://ngabbs.com/)观察到的[公开数据资源](https://img4.nga.cn/proxy/cache_attach/bbs_index_data.js)，2026-11-12快照去除图标、布局和个人占位数据后内置于`internal/nga/directory_seed.json`。仅解析固定赋值包装内的JSON，不执行脚本。当前快照包含659个去重入口（普通板块与合集）。目录不涵盖NGA所有未公开板块。

## 已验证

- 真实公开资源无需登录返回HTTP200；支持GB18030及UTF-8，正负板块编号、数组／对象目录、重复入口合并、合集隔离和常用别名。
- 固定HTTPS目录请求不携带论坛Cookie或Authorization；限制重定向目标、15秒请求时间和1MiB响应。拒绝HTML、脚本尾部、截断和空目录，失败仍保留已有目录。
- 本地缓存独立于账号数据；过期24小时后刷新，损坏时回退内置目录。搜索在本机完成，规范化全角／大小写，多个关键词匹配；搜索索引和结果缓存，列表采用原生虚拟列表。
- 原生测试覆盖按名添加并打开、已有自定义名称、唯一／歧义Enter、Esc、普通和手动添加保存失败、合集链接防误加、刷新去重、窗口关闭后返回、缓存损坏、演示／真实数据隔离和关闭中止。
- 使用实际原生渲染器检查深色、浅色、NGA经典屎黄色主题，980×620与760×520窗口；搜索输入、刷新、关闭和手动添加入口均在窗口内。离线预览不包含真实账号或帖子。

## 兼容边界

- 原生浏览合集需要不同的论坛查询与上下文，暂不引入；搜索结果明确说明，并提供官方页面入口。
- 目录后台刷新只在打开添加窗口或主动刷新时触发；目录失效不会影响原有板块和帖子阅读。新增缓存不包含登录或账号收藏数据。
- 不修改已公开的旧标签或资产，不替换用户正在D盘运行的程序和数据。Windows与两种Mac继续采用便携ZIP和已有签名自动更新流程。
- Mac系统GUI及实际更新仍需真机核验；CI构建与原生测试不等同于系统安全软件认证。
