# 表情修复、工位摸鱼图标与正式版

用户要求修复复制丢表情和代码内容误触发动画，随后将已完成的0.1.12本地体验优化推送GitHub，发布正式版。最新请求撤销上一轮“暂不推送”的限制。本轮复用唯一正式checkout及现有体验分支，不触碰D盘程序或账号数据。

用户说明Log是误写，实际要Logo，不增加运行日志功能。最终图标主角必须是戴眼镜、格子衫、发福的中年男性，在工位偷偷刷NGA，卡通风格。使用图像生成产物，深棕圆角底、奶油色屏幕和清晰NGA标记，透明外沿。同一PNG用于原生窗口、托盘、Windows/macOS打包及README。

## 表情

- 原因：MyGo LinkIcon明确按装饰处理，复制时丢弃图标；当前动画检测只扫描URI原文。
- 不修改依赖缓存，不复制整个UI框架。使用公开的原生富文本和可选区复制API，为含表情段落保留对象位置与NGA代码的映射，复制时输出`[s:组:名称]`；普通无表情文档保留现有Markdown行为。
- 图片仍按需，表情只允许固定内置白名单。正文与引用、连续表情、部分选区和跨段复制要测试，不混入对象替代字符或内部URI。
- 动画识别解析Markdown结构，只统计实际会渲染的内置表情链接；代码块、行内代码、普通文字地址、未知链接不调度重绘。
- 必要时为含表情的本地复制提供明确的纯文字／NGA代码语义，不能把无意义对象字符放入剪贴板。

## 正式发布

正式版使用0.1.13（初次0.1.12标签的Mac字体高度测试失败，修正后保留原标签不改写），GitHub发布标记为非预发布并设为Latest。保持签名更新、三平台包、完整摘要及App短说明校验，只有完整资产验证通过后才公开。旧标签和公开资产不覆盖。Windows/macOS仍为免安装ZIP，Mac按现有ad-hoc签名流程，不声称Developer ID或公证。

先做本地回归、三主题和小图标检查，一次独立完整分支审查，修复重要问题后合并、推送和创建新标签。CI生成草稿，核验三平台资产后离线签名上传并发布，最后核验公开资产和自动更新源。密钥只用于原有离线签名命令，不打印或上传。
