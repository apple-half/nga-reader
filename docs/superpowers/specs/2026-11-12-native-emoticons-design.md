# NGA 原生行内表情

用户要求在App中显示NGA自带表情，并注意尺寸。当前BBCode把`[s:ac:哭笑]`统一替换为`[表情]`；旧数字表情还可能被当作删除线标签吞掉后文。只实现本次表情显示；此前体验建议与自动续页仍是后续清单。

官方`https://img4.nga.cn/common_res/js_bbscode_core.js`公开映射含265个表情，分默认、ac、a2、ng、pst、dt、pg七组。仅提取数据、不执行脚本。Go直连图片遇到HTTP567；正常浏览器可以读取全部资源。已通过浏览器公开资源导出取得原始图片，不导出Cookie、个人资料或验证状态，不绕过验证。将固定图片与名称映射内置，原生绘制，运行时不为表情打开WebView或请求CDN。

沿用MyGo支持的`markdown.Options.LinkIcon`原生行内对象，内部地址仅能映射内置白名单文件，名称作为提示及可访问性描述。普通附件继续点击展示，`LoadImage`继续为空，未知表情保留可读原始代码；引用和HTML兼容正文中的官方表情也识别，代码块不转换。

尺寸保持原比例，不放大超过原图；通常表情最大高度为正文2倍字号（上限32 DIP），最大宽度为3倍字号（上限56 DIP）。较大素材（任一边超过100像素）允许最大高度3倍字号（上限48 DIP），最大宽度4倍字号（上限72 DIP），不铺满阅读区。字体12～22、三个主题及窄阅读栏检查；下载失败占位问题通过内置素材消除。加载时只解码当前实际使用的图片，同一资源复用。

GIF按原始时序原生绘制，解码与帧数／像素预算有上限；可见的含动画楼层最多8次/秒请求重绘，不按表情各自建定时器。静态图片不持续重绘。内置素材单独保留来源和权利声明，不声称其适用项目MIT源码许可证，不采用第三方客户端代码／图片或其GPL许可证。
