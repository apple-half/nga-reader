# 阅读体验补齐设计

用户指出先前体验评估尚未落地，现补齐整批建议，并包含明确提出的滚动到底自动加载下一页。沿用 Go/MyGo 原生三栏，不增加依赖。用户此前授权自主决定细节及 GitHub 发布，本轮直接执行。

## 范围与体验

1. 布局：正文至少 420 DIP；优先收窄分栏，仍不够时暂时收起侧栏。提供侧栏折叠、恢复默认分栏。窗口记忆正常尺寸，跨屏不恢复绝对坐标，避免跑到屏幕外。工具栏去掉冗余文字，保持按钮完整。
2. 连续阅读：默认开启，距当前最后楼层底部 180 DIP 时请求一页并追加，保留已有正文和滚动位置。不自动加载普通图片。每次仅一个请求，同一失败只显示重试，不自动循环重试；已到底明确提示。保留手动翻页、跳页、从头阅读和只看楼主。
   - 每个已载入楼层记录原始页码，阅读进度按可见楼层页码保存。只看楼主不覆盖完整阅读位置。
   - 请求沿用取消令牌并校验话题、账号、筛选条件，切换目标后旧响应丢弃。按 PID（无 PID 时按楼层）去重；空页、重复页停止续页，总页数未知时仍只试一页。
   - 为控制原生长文布局成本，一次连续保留最多 10 页或 200 楼（先到为准），到上限显示“继续下一段”，点击进入下一页；不暗中移除上方内容。
   - 同目标同页刷新保留正文和位置，成功替换当前连续段、恢复楼层；失败保留正文并显示重试。换页／换帖使用独立加载状态，不能把旧内容当新帖。
3. 板块：名称默认不展示 ID；管理入口可重命名、上移、下移、移除。移除仅影响本地列表，最后一个板块不允许移除。先保存成功再改变可见状态，错误原地显示。
4. 导航：本会话阅读后退／前进（最多 50 个位置），记录话题、可见页、楼层、筛选。空白页提供当前账号“继续上次阅读”；启动不强行联网打开旧帖。
5. 查找：Ctrl/Cmd+F 搜索当前已载入正文，忽略大小写，按楼层匹配，展示匹配楼层计数并可上一处／下一处跳转。不为查找抓取未载入页。Escape 关闭。
6. 编辑：编辑／预览切换，复用安全按需 Markdown 和原生表情；不发送或准备额外请求。显示草稿已保存时间，失败保留原文与明确提示。发送仍走原有权限、账号和防重复保护。
7. 图片：点图后在当前已载入段形成去重图集，上一张／下一张、计数、缩放和重置。只导航用户明确选择的那一张，不预取，继续使用独立临时 WebView 和图床白名单。
8. 小修：热门改成本页按回复数，空筛选结果提供清除，补齐快捷键说明。

## 实现选择

- 采用有界追加而不是无限保留所有页，成本是超长帖每段需一次点击，避免几千楼同时布局拖慢窗口。
- 采用已有 MyGo 原生 UI 和滚动观察，拒绝把整篇阅读区改为网页，保留目前安全和便携方式。
- 查找按楼层定位并显示结果说明，不改写 BBCode/Markdown 插入高亮标记，避免破坏链接、引用和表情。
- 图片缩放调用系统 Page.SetZoomFactor，不注入图床脚本；个别图片文档的视觉效果由系统引擎决定。

## 验收

原生小窗口与三主题预览、连续页保位与断网恢复／重复响应／切换取消／账号隔离／只看楼主、导航锚点、正文搜索、板块保存失败、编辑预览无外部图片加载、图集无预取。全套 Go/vet、登录脚本、打包测试，Windows 与两种 Mac CI 编译及免安装包验证。真机 Mac 和 NGA 实际发帖无法由离线测试替代，不做实际测试发帖。
