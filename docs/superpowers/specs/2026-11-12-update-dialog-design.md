# 更新提示可读性修复

用户反馈App内升级提示显示GitHub Markdown源码、下载表格和很长链接。已确认`view_updates.go`直接`ui.Text(info.Notes)`，而离线签名器默认把整份网页发布说明放进签名元数据。

沿用用户此前授权直接决定并完成的方式，不再追加设计确认。唯一GitHub checkout内使用功能分支；Go1.27.3/MyGo0.8.3，无新依赖，不修改已发布0.1.8标签或资产、不触碰D盘运行程序及数据。

方案：App与网页使用分别撰写的说明。新的签名更新说明为短段落和普通短横线列表，无表格、HTML或下载URL，旧客户端作为纯文字显示也能读清。新客户端复用现有原生Markdown组件显示列表和强调；对旧0.1.8说明优先取“本版改进”章节，其余内容可到完整发布页查看。签名格式和安装流程不变。

弹窗突出当前→新版本及预发布标记，说明独立滚动；状态、错误、进度和安装／重启操作固定可见。安装／待重启时收起改动清单，保留必要状态。提供完整说明或手动下载入口，保留自动检查偏好和既有草稿／账号保护。图片、HTML及代码不执行或主动加载。

取舍：只修复原生Markdown渲染仍会保留整页下载信息；只改发布说明则未来客户端仍无法呈现格式。采用两处共同修复。旧客户端的布局需升级后生效，但重新检查0.1.9时即可先收到简短文字说明。发布0.1.9三平台便携版。
