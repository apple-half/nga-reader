# 首页板块搜索添加

用户要求在App里按NGA首页板块名称搜索并添加，不必复制链接。沿用既有用户授权直接决定实现与发布，使用唯一GitHub checkout功能分支，不增加运行依赖，不触碰D盘程序／数据、既有账号或签名私钥。

已从用户指定的`ngabbs.com`首页确认官方目录资源`https://img4.nga.cn/proxy/cache_attach/bbs_index_data.js`。无需登录直接请求可返回约43KB的GB18030数据，内容为固定变量赋值加JSON。只解析数据，不执行脚本。目录含普通板块及合集；后者有`stid`并共享上级`fid`，不可误作普通板块添加。

方案：内置该公开目录快照，补充本地缓存；打开添加窗口时目录过期24小时才后台读取一次官方资源，另提供手动刷新。搜索在本地按名称、简介、分类、编号和常用别名匹配，支持大小写／全角兼容。网络失败仍可搜索内置或缓存目录，不携带NGA会话，不逐字请求论坛。

“我的板块”旁加号默认打开名称搜索；结果展示板块名、分类和简介，点击添加并打开。已有板块显示打开入口，不重复添加或覆盖自定义名称。保留链接／编号添加页。合集明确标为暂不支持原生添加，可主动打开官方页面，不映射到父板块。目录范围为首页公开入口，不承诺搜索未公开的全部论坛版面。

本地保存失败时保持窗口和输入，不显示添加成功。键盘Enter只在唯一匹配的普通板块时添加／打开，Esc关闭；搜索、空状态、目录刷新和失败提示明确。三个主题、980×620与760×520检查。演示使用公开内置目录，不发目录请求或写缓存。发布0.1.10 Windows与两种Mac便携包，保留原更新与发帖保护。

取舍：只做在线查询会受首页访问验证影响；只内置目录会长期过时。采用官方资源、快照和缓存结合。合集原生浏览涉及不同协议与身份，不在本次引入，明确提供官网入口。
