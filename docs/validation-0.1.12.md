# 0.1.12 本地阅读体验验证（尚未发布）

本轮按用户最新要求仅本地开发，不推送 GitHub、不创建标签、不触发 CI、不发布 Release 或更新索引。公开下载和更新源仍是 0.1.11；本文不表示 0.1.12 已对外发布。

## 本地实现

- 正文宽度保护、侧栏折叠／恢复默认分栏、正常窗口尺寸记忆。尺寸不恢复绝对坐标，避免跨屏移位。
- 默认开启向下滚动自动续页，保留已有内容与滚动；每次仅一页请求，失败提供手动重试；空页／全重复页停止。单段最多10页或200楼，整页超过上限则进入下一段，不截掉半页。
- 追加楼层带原始页码；可见页码、阅读锚点、字号／宽度重排、页内顶部和原帖链接均对应可见页。“只看楼主”不覆盖全帖进度。
- 同页刷新保留正文，成功只替换该页，失败不清空。话题／账号／筛选条件变化使续页旧响应失效。
- 本地板块重命名、排序、移除；先持久化成功再替换列表，保留至少一个板块；默认隐藏编号。清除话题筛选及“本页按回复数”明确范围。
- 本次运行的阅读后退／前进，最多50个位置，按账号隔离；空白页可继续当前账号上次阅读。
- Ctrl/Cmd+F 查找已载入正文与引用，按匹配楼层定位，不改写正文或抓取其他页；查找期间暂停自动续页。
- 原生编辑预览与明确草稿保存时间；普通图片按需，预览不发表内容或发起额外准备请求。
- 已载入图片图集，上一张／下一张和25%至400%系统页面缩放；最多500个去重地址，只加载用户选中的一张，不预取。
- 设置正文改为可滚动内容，小窗口仍可完整操作底部按钮。内置使用说明同步更新。

## 验证边界

- 本轮不做真实 NGA 测试发帖，不修改用户正在运行的 D 盘程序或其数据。
- 图床验证仍依赖用户在独立临时系统 WebView 内完成；缩放采用系统页面 API，实际效果由系统图片文档决定。原生测试不替代真实系统 WebView 验证。
- 短页本身无需滚动时使用“加载下一页”，避免切换筛选／恢复布局被误判为向下滚动。
- 连续阅读采用有界分段，超长帖子每段需点击一次“继续下一段”；正文搜索定位到楼层，不做逐字高亮。
- 图片列表只来自当前已载入段；后退／前进不跨进程保存。Mac 当前不触发远端构建，签名与真机运行留待后续。
